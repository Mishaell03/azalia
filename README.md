# 🌿 Azalia – Экосистема для продажи растений и комплексного ухода за ними.

Репозиторий проекта: https://github.com/Mishaell03/azalia

## Мини-презентация проекта

**Azalia** — это мобильная экосистема, которая объединяет:
- витрину и продажу растений;
- оформление заказов и оплату;
- персональные сценарии ухода за растениями (важные даты, напоминания, календарные события);
- админ-инструменты для управления контентом и процессами.

Проект ориентирован на полный цикл: от выбора растения до его сопровождения после покупки.

## Техническое представление

- Frontend: Flutter (Dart), кроссплатформенное мобильное приложение.
- Backend: FastAPI (Python), REST API, SQLite.
- Интеграции: Telegram bot, платежный модуль (YooKassa), уведомления.
- Архитектура: monorepo из двух основных модулей `flutter/` и `back/`.

## Быстрый запуск фронтенда (для проверки)

1. Перейдите в модуль фронтенда:

```bash
cd flutter
```

2. Установите зависимости:

```bash
flutter pub get
```

3. Проверьте окружение и устройства:

```bash
flutter doctor
flutter devices
```

4. Убедитесь, что API-адрес корректен в `flutter/lib/backend/api_config.dart`.

5. Запустите приложение:

```bash
flutter run
```

Или на конкретном устройстве:

```bash
flutter run -d <device_id>
```

## Важно для проверяющих

- Авторизация в приложении выполняется через ваш Telegram-аккаунт.
- Получить функционал администратора можно также через Telegram-связку: на главной странице есть кнопка **«Стать администратором»**.
- Для более быстрой загрузки приложения рекомендуется отключить VPN-трафик на время проверки.
- Сервер маломощный, поэтому часть экранов и запросов может прогружаться дольше обычного.

## Запуск бэкенда (при необходимости локальной проверки)

1. Перейдите в модуль бэкенда:

```bash
cd back
```

2. Создайте виртуальное окружение и установите зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

3. Запустите API:

```bash
python main.py
```

## Важно про env в бэкенде

Если вы запускаете backend локально, перед стартом **обязательно измените значения в `back/.env` под свое окружение**.

Минимум проверьте:
- `SECRET_KEY`
- `DATABASE_URL`
- `DEBUG`
- `PORT`
- `API_BASE_URL`
- `BOT_TOKEN` (если используете бота, либо авторизацию можно произвести через test/auth.py)
- `YOOKASSA_SHOP_ID`, `YOOKASSA_SDK`, `YOOKASSA_API_KEY` (если проверяете оплату)
