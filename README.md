# 🌿 Azalia - Магазин комнатных растений

Полнофункциональное мобильное приложение для продажи растений в горшках. Приложение
разработано с использованием **Flutter** (фронтенд) и **Python** (бэкенд) и позволяет покупателям
легко выбирать и заказывать растения.

## 📱 Функциональность

### Для покупателей

- ✅ **Каталог растений** - просмотр всех доступных товаров с описанием, фото и ценами
- ✅ **Категоризация** - фильтрация растений по категориям
- ✅ **Корзина покупок** - добавление товаров и управление заказом
- ✅ **Система аутентификации** - регистрация и вход в аккаунт через Telegram
- ✅ **Профиль пользователя** - управление данными профиля
- ✅ **Список избранного** - сохранение понравившихся товаров
- ✅ **Корзина для покупок** - сохранение товаров которые будут преобретаться

### В разработке

- 🔧 **Админ-панель** - управление товарами, заказами, сотрудниками и аналитикой продаж
- 🔧 **История заказов** - управение купленными товарами
- 🔧 **Анимации** - добавление красивых переходов с 1 страницы на другую, добавление загрузочной
  страницы и приветствия
- 🔧 **Система уведомлений** - добавление опевещений через Telegramm бота а так-же через само
  приложение

## 🛠️ Технологический стек

### Frontend

- **Dart** - язык программирования
- **Flutter** - кроссплатформенный фреймворк

### Backend

- **Python** - язык программирования

## Установка и запуск

### Краткая инструкция для проверки фронтенда

Если вы проверяете **только фронтенд**, достаточно запустить Flutter‑приложение.  
Backend уже развернут на сервере, локально поднимать его **не требуется**.

### Рекомендация по проверке кода фронтенда (с чего начать)

- **Начинайте ревью с админ‑части**: код админки сейчас более показателен и стабильнее по структуре.
- **Пользовательская часть будет частично перерабатываться**: планируется реорганизация кода местами для упрощения дальнейшего обслуживания приложения.
- **Кэширование**: будет добавлено кэширование данных **на всех страницах**, поэтому текущие реализации на экранах будет меняться.

1. Установите Flutter SDK (и Android Studio / Xcode).
2. Перейдите в корень проекта:

```bash
cd azalia
```

3. Установите зависимости:

```bash
flutter pub get
```

4. Убедитесь, что базовый URL API в `lib/backend/api_config.dart` указывает на прод‑сервер (по
   умолчанию уже так настроено):

```dart

const String API_BASE_URL = 'http://nebinance.ru:5000/api';
```
PS: сервер маломощный, поэтому все запросы могут проходить с задержкой

5. Запустите приложение на удобном устройстве/эмуляторе (например IOS‑эмуляторе):

```bash
flutter run -d <device_name>
# или
flutter run
```

Все основные пользовательские сценарии (авторизация, каталог, корзина, профиль, избранное) будут
работать через уже развернутый backend.

### Требования

#### Frontend

- [Flutter SDK](https://flutter.dev/docs/get-started/install)
- [Dart SDK](https://dart.dev/get-dart)
- Xcode или Android Studio

#### Backend (развернут на сервере)

- Python 3.9+

### Запуск Backend

1. Перейти в папку проекта:

```bash
cd azalia/back
```

2. Создать виртуальное окружение (по возможности, но можно пропустить шаг):

```bash
python3 -m venv venv
source venv/bin/activate
```

3. Установить зависимости:

```bash
pip install -r requirements.txt
```

4. Запустить Flask приложение:

```bash
python app.py
```

Backend будет доступен по адресу `http://ip_address:5000/api/***`.
В данный момент он доступен по адресу `http://nebinance.ru:5000/api/***`

### Запуск Frontend

1. Перейти в папку проекта:

```bash
cd azalia
```

2. Получить зависимости:

```bash
flutter pub get
```

3. Запустить приложение:

**На iOS/Android симуляторе:**

```bash
flutter run -d device_name
```

**На реальном устройстве:**

```bash
flutter run
```

### Frontend API конфигурация

Измените базовый URL API в файле [lib/backend/api_config.dart](lib/backend/api_config.dart):

```dart

const String API_BASE_URL = 'http://nebinance.ru:5000/api';
```

### Backend конфигурация

Настройка БД и других параметров в файле [back/db.py](back/db.py).

### Временная debug‑функция в Telegram‑боте

В файле `back/bot.py` временно добавлена debug‑кнопка **«⭐ Сделать меня админом (debug)»**,  
которая напрямую через БД назначает текущего Telegram‑пользователя администратором (позиция с
`id = 4`).  
Функция предназначена **только для локальной отладки** и не будет использоваться в продакшене.
